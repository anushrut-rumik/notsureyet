# Reach

The intended users ask a personal agent to perform wallet work in WhatsApp. They
create a separate agent wallet, fund it, read balances, review exact payments,
approve by chat and return later for task progress and transaction receipts.
No new web interface is required.

The existing Ira whatsmeow sidecar contract is reused with a dedicated line and
an independent Redis consumer. This repository does not inherit production users,
contact bindings or traffic by copying source. No active-user, handset-delivery,
public-deployment or prize-eligibility claim is made.

The hackathon demonstration should show one full task, restart recovery, a saved
transaction hash that is checked rather than sent again, and an independent Arkiv
query. These are the intended evidence targets, not completed live observations.
