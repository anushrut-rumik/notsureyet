# Reach

## Who uses this today, and will they use the Arkiv part?

This is a developer-run Ira prototype. The observed setup has a dedicated WhatsApp
test adapter, a connected MetaMask identity and an agent-created wallet. These are
development identities, not proof of multiple active users. This independent repo
does not inherit production Ira users/traffic.

Users ask Ira to research, create files, wait/remind or manage explicitly approved
payments. Arkiv powers their task lists, progress and restart recovery.
Judges/developers can run README's independent SDK query today.

## Can people try it, and will it ship after Mumbai?

The repo is public. README covers local setup, funding, key recovery and queries.
Interactive use needs personal inference credentials, a funded Rabdi wallet and
access key. WhatsApp needs its configured dedicated adapter. The loopback HTTP API
is not a public authenticated service. No hosted public demo/adoption is claimed.

The implementation and regressions support continued Ira integration. Production
rollout and a post-Mumbai service commitment remain team decisions; no unapproved
release date is asserted. [Actual evidence](demo.md) separates live Rabdi storage
from simulated cross-chain execution.
