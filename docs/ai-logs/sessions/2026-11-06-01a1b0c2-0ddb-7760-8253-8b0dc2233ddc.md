### On what basis does it store something?

**Your application decides when to save. Arkiv does not read the chat and decide what matters.**

The code requests checkpoints when a task is created, its status or notes change, execution starts, or certain action results are recorded. It compares the snapshot with the last saved version and normally skips an unchanged snapshot. Unfinished tasks also have a weekly refresh mechanism.

Each checkpoint has public fields that let the application find it:

| Field | Purpose |
|---|---|
| `instance` | Groups records for a particular chat and storage wallet. |
| `task` | Identifies the task. |
| `revision` | Identifies the version; the highest revision is treated as current. |
| `operation` | A fingerprint of that particular write. |
| `encrypted` | Holds the encrypted task snapshot. |
